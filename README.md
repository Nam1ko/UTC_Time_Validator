# UTC Time Validator

## Описание проекта

Программа для проверки и поиска временных отметок в формате UTC.

## Возможности

- Поиск времени в тексте.
- Поиск времени на веб-страницах.
- Поиск времени в файлах.

## Структура проекта

- `main.py` — запуск программы.
- `application` — основная логика.
- `domain` — модель временной отметки UTC.
- `infrastructure` — работа с файлами и веб-страницами.
- `presentation` — консольное меню.
